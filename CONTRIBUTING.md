# Contributing

Before contributing to this project, please first discuss the change you wish to make via issue, or on Discord.

## Pull Request Guidelines

- For consistency, please only use spaces for indentation.
- Avoid non-meaningful additions or tiny bug fixes, open an issue beforehand.
- I suggest using [SonarLint](https://www.sonarlint.org) in your IDE (as for CoreProtect) for consistency.
- When adding new functionality, please also be sure to update the documentation/README as well.
- No Vibe-coded AI slop. 
- Always test your code.
- Use common sense.
